## Prompt Caching 优化

针对 Anthropic Claude 的 Prompt Caching 特性做了专门优化：

```python
# agent/prompt_caching.py
# 策略：系统提示组装完成后保持不变，触发 Anthropic 缓存
# 缓存命中条件：相同的系统提示 + 相同的前 N 条消息

# 标记缓存断点
messages[0]["content"][0]["cache_control"] = {"type": "ephemeral"}
```

这确保每次对话的系统提示（包含 MEMORY.md/USER.md/Skills 等）在同一会话内不重复计费。

## 并行工具执行

```python
# run_agent.py 中的并发控制
_PARALLEL_SAFE_TOOLS = frozenset({
    "web_search", "web_extract",
    "read_file", "search_files",
    "vision_analyze", "session_search",
    "skill_view", "skills_list",
    ...
})

_NEVER_PARALLEL_TOOLS = frozenset({
    "clarify",            # 需要等待用户交互
})

_PATH_SCOPED_TOOLS = frozenset({
    "read_file", "write_file", "patch",  # 路径不冲突时可并行
})
```

并行安全工具 → `ThreadPoolExecutor` 并发执行
串行工具（terminal/write_file/clarify 等）→ 顺序执行

## Smart Model Routing

```python
# agent/smart_model_routing.py
# 简单/短对话自动路由到便宜模型
def should_use_cheap_model(messages: list) -> bool:
    # 条件：短消息 + 无工具历史 + 简单意图判断
    return len(messages) <= 2 and is_simple_query(messages[-1]["content"])
```

- 复杂任务 → 主模型（如 Claude Opus）
- 简单问答 → 便宜模型（如 Gemini Flash）
- 摘要/压缩 → 辅助模型（通过 `auxiliary_client.py`）
