# 09 多轮会话管理

## 概览对比

| 维度 | deer-flow | hermes-agent | nanobot |
|------|-----------|--------------|---------|
| **持久化后端** | LangGraph Checkpointer（内存/SQLite/Postgres）| SQLite WAL + FTS5 | JSON 文件（原子写）|
| **会话标识** | `thread_id`（UUID）| `session_id`（时间戳 + UUID）| `session_key`（渠道:用户ID）|
| **消息格式** | LangChain Message 对象（带 reducer）| OpenAI 格式 dict + SQLite 行 | OpenAI 格式 dict 数组 |
| **历史压缩** | `DeerFlowSummarizationMiddleware` | 压缩会话（parent_session_id 链）| Consolidator（token 触发）|
| **上下文截断** | token 预算触发，中间件处理 | 超限触发，生成新压缩会话 | token 预算 × consolidation_ratio |
| **多用户隔离** | `thread_id` 不同即隔离 | `user_id` + `source` 维度 | `session_key` = `{channel}:{user_id}` |
| **搜索能力** | 无（依赖 LangGraph 标准 checkpoint）| FTS5 全文检索 + trigram（CJK）| 无 |

## deer-flow：LangGraph Checkpointer

### ThreadState 数据结构

```python
# agents/thread_state.py
class ThreadState(AgentState):
    # AgentState 已有：
    #   messages: Annotated[list[BaseMessage], add_messages]  # append-only reducer
    #   remaining_steps: int

    sandbox: NotRequired[SandboxState | None]       # 沙箱状态（sandbox_id, container_id）
    thread_data: NotRequired[ThreadDataState | None] # 工作目录路径、上传/输出文件
    title: NotRequired[str | None]                   # 会话标题（TitleMiddleware 自动生成）
    artifacts: Annotated[list[str], merge_artifacts] # 去重 reducer
    todos: NotRequired[list | None]
    uploaded_files: NotRequired[list[dict] | None]
    viewed_images: Annotated[dict[str, ViewedImageData], merge_viewed_images]
```

**Reducer 设计：**
- `messages`：`add_messages` reducer——仅追加，永不覆盖历史
- `artifacts`：`merge_artifacts` reducer——基于 path 去重合并
- `viewed_images`：`merge_viewed_images` reducer——支持 clear/merge 两种操作

### 三种 Checkpointer 后端

```python
# runtime/checkpointer/provider.py
def make_checkpointer(config):
    if config.type == "memory":
        return InMemorySaver()        # 进程内，重启丢失，用于开发

    elif config.type == "sqlite":
        conn_str = f"sqlite:///{config.database_path}"
        return SqliteSaver.from_conn_string(conn_str)  # 默认，单节点生产

    elif config.type == "postgres":
        return PostgresSaver.from_conn_string(config.connection_string)  # 多节点
```

**config.yaml 配置：**

```yaml
checkpointer:
  type: sqlite           # memory / sqlite / postgres
  database_path: ./.deer-flow/checkpoints.db
  # connection_string: postgresql://...   # postgres 专用
```

### 会话加载与恢复

```python
# 每次请求传入 thread_id → LangGraph 自动加载历史 state
await agent.astream(
    input={"messages": [HumanMessage(content=user_message)]},
    config={
        "configurable": {
            "thread_id": thread_id,           # 关键：会话标识
            "thinking_enabled": True,
        },
        "recursion_limit": 100,
    },
    stream_mode="values",
)
```

LangGraph 在每次 `astream/invoke` 时：
1. 从 checkpointer 加载 `thread_id` 对应的最新 checkpoint（含完整 `ThreadState`）
2. 将新的用户消息与历史 `messages` 合并（通过 `add_messages` reducer）
3. 执行图的一轮运行
4. 将更新后的 `ThreadState` 保存回 checkpointer

### 上下文压缩（Summarization Middleware）

当消息总 token 接近模型上下文窗口时触发：

```python
# agents/middlewares/summarization_middleware.py（DeerFlowSummarizationMiddleware）

class DeerFlowSummarizationMiddleware:
    async def before_model(self, state, config):
        token_count = estimate_tokens(state["messages"])
        if token_count < self.config.summarization_threshold:
            return state

        # 保留最近 N 条消息，对更早的内容调用 LLM 生成摘要
        recent = state["messages"][-self.config.keep_recent:]
        old = state["messages"][:-self.config.keep_recent]

        summary = await self.llm.ainvoke(
            [SystemMessage(content=SUMMARIZATION_PROMPT)] + old
        )

        # 用摘要替换旧消息
        state["messages"] = [
            SystemMessage(content=f"<conversation_summary>{summary.content}</conversation_summary>")
        ] + recent
        return state
```

## hermes-agent：SQLite WAL + FTS5

### Schema 设计

```sql
-- hermes_state.py  SCHEMA_VERSION = 11

CREATE TABLE sessions (
    id TEXT PRIMARY KEY,             -- "20260508_100000_ab12cd34"
    source TEXT NOT NULL,            -- 'cli' | 'telegram' | 'discord' | ...
    user_id TEXT,
    model TEXT,
    system_prompt TEXT,              -- 快照（用于前缀缓存复用）
    parent_session_id TEXT,          -- 压缩会话链（compression continuation）
    started_at REAL NOT NULL,
    ended_at REAL,
    end_reason TEXT,                 -- 'natural' | 'compression' | 'interrupted' | ...
    FOREIGN KEY (parent_session_id) REFERENCES sessions(id)
);

CREATE TABLE messages (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    role TEXT NOT NULL,              -- 'user' | 'assistant' | 'tool'
    content TEXT,
    tool_call_id TEXT,
    tool_calls TEXT,                 -- JSON
    tool_name TEXT,
    timestamp REAL NOT NULL,
    reasoning TEXT,                  -- thinking content（已完成）
    reasoning_content TEXT,
    reasoning_details TEXT,          -- JSON，完整 thinking blocks
    codex_reasoning_items TEXT,      -- OpenAI Codex 推理
    codex_message_items TEXT
);

-- FTS5 全文索引（Latin 分词，BM25 排名）
CREATE VIRTUAL TABLE messages_fts USING fts5(content);
-- FTS5 Trigram 索引（CJK 子串检索）
CREATE VIRTUAL TABLE messages_fts_trigram USING fts5(content, tokenize='trigram');
```

### WAL 模式写入保护

```python
# hermes_state.py
class HermesStateDB:
    _WRITE_MAX_RETRIES = 15
    _WRITE_RETRY_MIN_S = 0.020   # 20ms
    _WRITE_RETRY_MAX_S = 0.150   # 150ms

    def _execute_write(self, fn):
        for attempt in range(self._WRITE_MAX_RETRIES):
            try:
                self._conn.execute("BEGIN IMMEDIATE")  # 独占写锁
                result = fn(self._conn)
                self._conn.commit()
                # 每 50 次写入做一次 PASSIVE WAL checkpoint
                if self._write_count % 50 == 0:
                    self._conn.execute("PRAGMA wal_checkpoint(PASSIVE)")
                return result
            except sqlite3.OperationalError as exc:
                if "locked" in str(exc).lower():
                    time.sleep(random.uniform(0.020, 0.150))
                    continue
                raise
```

### 压缩会话链（Compression Continuation）

当会话 token 接近上下文窗口时，hermes 创建新会话并通过 `parent_session_id` 链接：

```
session_20260501_001  (end_reason="compression")
    └── parent_session_id = None

session_20260501_002  (end_reason="compression")
    └── parent_session_id = "session_20260501_001"

session_20260508_001  (active)
    └── parent_session_id = "session_20260501_002"
```

**hermes-agent 的链式压缩独特之处：** 旧会话数据完整保留在 SQLite，新会话通过 `parent_session_id` 引用旧会话。这允许后续审计/搜索所有历史，而不仅是压缩摘要。

### FTS5 全文检索

```python
# hermes_state.py - search_messages()
def search_messages(self, query: str, session_id: str = None, limit: int = 20):
    # 自动选择索引：Latin 文字用 fts5，CJK 内容用 trigram
    has_cjk = bool(re.search(r'[\u4e00-\u9fff\u3040-\u30ff]', query))
    table = "messages_fts_trigram" if has_cjk else "messages_fts"

    sql = f"""
    SELECT m.*, bm25({table}) AS rank
    FROM {table}
    JOIN messages m ON {table}.rowid = m.id
    WHERE {table} MATCH ?
    ORDER BY rank
    LIMIT ?
    """
```

```python
# agent/loop.py
class AgentLoop:
    # 每个 session_key 一把锁，保证同一会话串行处理
    _session_locks: dict[str, asyncio.Lock] = defaultdict(asyncio.Lock)
```

## 横向对比：多轮会话设计总结

### 持久化方案对比

```
可靠性  ─────────────────────────────────────►
        JSON 文件         SQLite WAL          LangGraph Postgres
        (nanobot)         (hermes-agent)      (deer-flow 生产)
        ↑                 ↑                   ↑
        最简单             事务安全             多节点水平扩展
        原子写保证         FTS5 搜索           标准 SQL 备份
```

### 上下文压缩策略对比

| 项目 | 策略 | 触发条件 | 保留内容 |
|------|------|----------|----------|
| deer-flow | 替换旧消息为摘要 | token 阈值 | 最近 N 条 + 摘要 |
| hermes-agent | 创建新压缩会话（链式） | token 阈值 | 原会话完整保留，新会话带摘要 |
| nanobot | history.jsonl 摘要 + 游标 | token 预算 × ratio | 游标后的完整消息 + 游标前的摘要 |

### 会话搜索能力

| 项目 | 搜索能力 | 适用场景 |
|------|----------|----------|
| deer-flow | 无（依赖 LangGraph 标准）| 按 thread_id 精确加载 |
| hermes-agent | FTS5 BM25 + trigram CJK | 跨会话语义搜索 |
| nanobot | 无（文件系统遍历）| 按 session_key 精确加载 |
