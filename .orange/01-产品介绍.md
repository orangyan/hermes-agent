# 01 产品介绍

## 项目是什么

**Hermes Agent** 是由 [Nous Research](https://nousresearch.com) 构建的**自我提升型 AI Agent**，当前版本 `v0.8.0`，MIT 许可证。

> "The self-improving AI agent — it creates skills from experience, improves them during use, nudges itself to persist knowledge, searches its own past conversations, and builds a deepening model of who you are across sessions."

它不只是一个 AI 助手，而是一个**会学习、会成长**的 AI Agent：
- 从经验中创建技能（Skills）
- 使用中改进技能
- 主动提醒自己持久化知识
- 跨会话搜索自己的历史对话
- 构建越来越深的用户模型

## 解决的问题

| 痛点 | Hermes 的解决方案 |
|------|------------------|
| 传统 AI 无学习能力，每次从零开始 | Skills（程序性记忆）+ Memory（事实记忆）+ Session Search（历史召回）三层递进 |
| Agent 只能在本地笔记本运行 | 6 种运行环境：本地 / Docker / SSH 远程 / Modal 云 / Daytona 云 / Singularity HPC |
| 多平台体验不统一 | 统一工具层，20+ 平台适配器，体验一致 |
| 模型锁定，无法灵活切换 | 统一 OpenAI SDK 格式，20+ Provider，零代码切换 |
| 缺乏研究工具（RL 训练） | 内置 Atropos RL 环境、批量轨迹生成、轨迹压缩 |
| 无 IDE 集成 | 支持 ACP（Agent Client Protocol），VS Code / Zed / JetBrains |

## 目标用户

- **个人技术用户**：希望拥有真正"了解自己"的个人 AI 助手
- **开发者**：需要将 AI 接入日常工作流（Telegram、Discord、Slack 等）
- **AI/ML 研究者**：需要 RL 训练、轨迹生成、批量处理能力
- **自托管用户**：希望在低成本 VPS 上自托管 AI，不依赖商业平台

## Nous Research 背景

Nous Research 是知名的开源 AI 研究组织，以：
- Hermes 系列微调模型（Hermes-3、NousHermes 等）
- 开放权重模型微调研究
- Agent 训练数据集

Hermes Agent 是其将研究成果落地为实用工具的产品化尝试，同时也是 Hermes 系列模型的首选 Agent 框架（自家模型 + 自家 Agent）。

## 与同类项目对比

| 维度 | Hermes Agent | DeerFlow | nanobot |
|------|-------------|---------|---------|
| **定位** | 自我提升型个人 Agent | Super Agent 运行时框架 | 极简研究型 Agent |
| **核心创新** | 自学习闭环（Skills + Memory + Search）| Middleware 链 + LangGraph | 超轻量核心 + 插件化 |
| **架构复杂度** | 中高（~50 个文件，完整工具生态）| 高（前后端分离，LangGraph）| 低（核心 <5 文件）|
| **IM 接入** | 20+ 平台 | 5 个平台（飞书/Slack/TG/企业微信/微信）| 10+ 平台 |
| **LLM Provider** | 20+ | 10+（OpenAI 兼容）| 20+（OpenAI 兼容）|
| **前端 WebUI** | 无（纯 CLI + 消息网关）| 完整 Next.js WebUI | WebUI（开发中）|
| **持久化** | SQLite WAL + FTS5 | LangGraph checkpoint（SQLite/PG）| JSON 文件 |
| **RL 研究** | 内置 Atropos 环境 | 无 | 无 |
| **IDE 集成** | ACP（VS Code / JetBrains）| 无 | 无 |
