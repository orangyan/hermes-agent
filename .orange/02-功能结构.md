## 技能系统（Skills）

### 技能的本质

技能 = **程序性记忆（Procedural Memory）**，Agent 如何完成某类任务的步骤指南。

与 DeerFlow Skills 相同的格式，兼容 [agentskills.io](https://agentskills.io) 开放标准。

### 技能文件结构

```
~/.hermes/skills/
├── coding/
│   ├── python-refactor/
│   │   └── SKILL.md
│   └── git-workflow/
│       └── SKILL.md
├── research/
│   └── market-analysis/
│       └── SKILL.md
└── personal/
    └── daily-standup/
        └── SKILL.md
```

### SKILL.md frontmatter

```yaml
---
name: python-refactor
description: 对 Python 代码进行系统性重构
platforms:            # 哪些平台启用（空=全部）
  - cli
  - telegram
requires_tools:       # 需要哪些工具可用
  - terminal
  - read_file
  - write_file
fallback_for:         # 作为某类任务的后备方案
  - code-review
---

# Python 代码重构技能

## 适用场景
...
```

### 技能自动创建

Agent 在完成复杂任务后，若判断值得记录为技能，会自动：
1. 调用 `skill_manage(action='create', ...)`
2. 将任务步骤总结为 SKILL.md
3. 供下次类似任务直接使用

每 15 次工具调用提醒一次（`creation_nudge_interval`）。

## 记忆系统

### 三层记忆架构

```
Layer 1: 工作记忆（当前会话）
  → SQLite WAL，当前对话消息列表
  → 受 ContextCompressor 管理

Layer 2: 持久记忆（跨会话）
  → ~/.hermes/MEMORY.md    Agent 自己的笔记（≤2200 字符）
  → ~/.hermes/USER.md      用户画像（≤1375 字符）
  → 每次会话注入系统提示
  → 由 `memory` 工具 CRUD

Layer 3: 历史召回（全历史搜索）
  → SQLite FTS5 虚拟表
  → session_search 工具跨会话全文检索
  → 辅助模型（Gemini Flash）生成摘要
```

### 记忆 Nudge 机制

- 每 10 轮对话（`nudge_interval`）：自动提醒 Agent "请更新你的记忆笔记"
- 每 15 次工具调用（`creation_nudge_interval`）：提醒 Agent "请考虑是否创建技能"
- 这是 Hermes 的"自我提升"核心机制

## 定时任务（Cron）

```bash
# 添加定时任务
/cron add "每天早上9点 检查 GitHub notifications 并发送摘要到 Telegram"

# 查看任务列表
/cron list

# 删除任务
/cron delete <id>
```

- 60 秒轮询检查到期任务
- 支持 cron 表达式和自然语言描述（由 LLM 解析）
- 任务完成后通过配置的渠道发送结果
