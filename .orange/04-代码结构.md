## 文件依赖链

```
tools/registry.py          (无依赖，最底层单例)
      ↑ 导入时自注册
tools/*.py                 (各工具在 module 导入时调用 registry.register())
      ↑
model_tools.py             (import tools/registry，触发所有工具的自动发现)
      ↑
run_agent.py               (核心，依赖 model_tools 获取工具列表)
      ↑
cli.py / gateway/run.py / batch_runner.py / environments/
(各入口点，依赖 run_agent.AIAgent)
```

## 关键类说明

| 类 | 文件 | 职责 |
|----|------|------|
| `AIAgent` | `run_agent.py` | 对话循环主类，管理消息历史、工具执行、迭代预算 |
| `HermesCLI` | `cli.py` | TUI 编排器，处理输入/输出、斜杠命令 |
| `GatewayRunner` | `gateway/run.py` | 消息网关主循环，分发消息到平台适配器 |
| `ToolRegistry` | `tools/registry.py` | 工具注册表单例，存储所有工具的 schema 和 handler |
| `SessionDB` | `hermes_state.py` | SQLite 会话存储，包含 FTS5 搜索索引 |
| `PromptBuilder` | `agent/prompt_builder.py` | 系统提示组装（SOUL + Skills + Memory）|
| `MemoryManager` | `agent/memory_manager.py` | 记忆管理，协调 builtin + 外部 provider |
| `ContextCompressor` | `agent/context_compressor.py` | 上下文超限时 LLM 压缩中间段 |
| `IterationBudget` | `run_agent.py`（内部类）| 线程安全的迭代次数控制器 |

## pyproject.toml Extras

```toml
[project.optional-dependencies]
messaging = ["python-telegram-bot", "discord.py", "slack-bolt", ...]
voice     = ["edge-tts", "elevenlabs", "faster-whisper", "sounddevice"]
browser   = ["playwright"]
cloud     = ["modal", "daytona"]
rl        = ["atropos", "tinker"]
acp       = ["agent-client-protocol"]
dev       = ["pytest", "pytest-asyncio", ...]
all       = [所有 extras]
```

Docker 镜像安装 `[all]` extras，包含所有可选功能。
