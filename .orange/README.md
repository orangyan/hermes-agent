## 项目一句话

**Hermes Agent** 是 Nous Research 开源的自我提升型 AI Agent，以 SQLite+FTS5 为核心存储，Skills（程序性记忆）+ Memory（事实记忆）+ Session Search（历史召回）三层递进，支持 20+ 平台接入和 20+ LLM Provider。
