# 07 部署与运行

## 快速安装

### 方式一：一键安装脚本（推荐）

```bash
# Linux / macOS / WSL2 / Android Termux
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
source ~/.bashrc

# 启动对话
hermes
```

### 方式二：uv 安装

```bash
uv tool install hermes-agent[all]
hermes
```

### 方式三：源码安装（开发）

```bash
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent

# 创建虚拟环境（Python 3.11+）
uv venv venv --python 3.11
source venv/bin/activate  # Linux/macOS
# 或 venv\Scripts\activate  # Windows

# 安装全部依赖
uv pip install -e ".[all,dev]"

# 运行测试
python -m pytest tests/ -q   # ~3000 个测试，约 3 分钟
```

## 配置文件

### 位置

```bash
~/.hermes/
├── config.yaml         # 主配置
├── .env                # API Keys（可选，配置优先级低于 config.yaml）
├── MEMORY.md           # Agent 知识笔记
├── USER.md             # 用户画像
├── skills/             # 技能目录
└── sessions/           # 会话数据库
```

### 核心配置结构（`config.yaml`）

```yaml
# 默认模型
model:
  default: "anthropic/claude-opus-4-5"   # 或任意 OpenRouter 模型 ID
  provider: "auto"                         # auto（自动检测）或指定 provider 名称
  base_url: "https://openrouter.ai/api/v1"

# API Keys
api_keys:
  openrouter: "sk-or-v1-..."
  anthropic: "sk-ant-..."
  openai: "sk-..."
  exa: "..."               # Web 搜索（推荐）
  firecrawl: "..."         # 网页提取（推荐）
  elevenlabs: "..."        # TTS（可选）

# 终端后端
terminal:
  backend: "local"         # local / ssh / docker / singularity / modal / daytona

# SSH 远程执行（terminal.backend=ssh 时）
ssh:
  host: "192.168.1.100"
  user: "ubuntu"
  key: "~/.ssh/id_rsa"

# 上下文压缩
compression:
  enabled: true
  threshold: 0.50          # 达到上下文窗口 50% 时压缩
  summary_model: "google/gemini-flash-2.5"

# 记忆系统
memory:
  memory_enabled: true
  user_profile_enabled: true
  nudge_interval: 10           # 每 10 轮对话提醒保存记忆
  creation_nudge_interval: 15  # 每 15 次工具调用提醒创建技能

# Agent 参数
agent:
  max_turns: 90
  reasoning_effort: "medium"   # low / medium / high（Anthropic thinking mode）

# 平台工具集配置
platform_toolsets:
  cli: ["hermes-cli"]
  telegram: ["hermes-telegram"]
  discord: ["hermes-discord"]

# 工具配置
tools:
  web_search:
    provider: "exa"            # exa / firecrawl / duckduckgo
  text_to_speech:
    provider: "edge-tts"       # edge-tts / elevenlabs / openai
  audio:
    stt_provider: "groq"       # groq / openai / local（faster-whisper）

# MCP 服务器
mcp:
  servers:
    filesystem:
      command: "npx"
      args: ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
      transport: "stdio"

# 外部记忆 provider（可选）
memory_providers:
  honcho:
    enabled: false
    api_key: "..."
    app_id: "..."
```

## 消息网关配置

### 交互式配置

```bash
hermes gateway setup   # 逐步引导配置各平台
hermes gateway start   # 启动网关
```

### 手动配置（以 Telegram 为例）

```yaml
# config.yaml
channels:
  telegram:
    enabled: true
    token: "1234567890:AAF..."   # BotFather 给的 token
    allowed_users: []            # 空=允许所有用户，填 user_id 列表=白名单
    assistant_id: "default"      # 路由到哪个 Agent（SOUL.md 配置）
```

```bash
hermes gateway start
# 监听所有 enabled=true 的渠道
```

### 支持的渠道配置项

```yaml
channels:
  telegram:
    enabled: true / false
    token: "..."
  discord:
    enabled: true
    token: "..."
    guild_ids: [12345678]      # 指定 Server（空=所有）
    allowed_channels: []       # 白名单频道
  slack:
    enabled: true
    bot_token: "xoxb-..."
    app_token: "xapp-..."      # Socket Mode 需要

    enabled: true
    app_id: "cli_..."
    app_secret: "..."
    verification_token: "..."
  email:
    enabled: true
    imap_host: "imap.gmail.com"
    smtp_host: "smtp.gmail.com"
    address: "bot@gmail.com"
```

## Docker 部署

### 基础 Docker 运行

```bash
# 运行（挂载 ~/.hermes 持久化数据）
docker run -d \
  --name hermes \
  -v ~/.hermes:/opt/data \
  -e OPENROUTER_API_KEY=sk-or-v1-xxx \
  -e ANTHROPIC_API_KEY=sk-ant-xxx \
  ghcr.io/nousresearch/hermes-agent

# 进入 CLI 对话
docker exec -it hermes hermes chat
```

### Dockerfile 要点

```dockerfile
# 基于 Debian 13.4
FROM debian:trixie-slim

# 使用 astral-sh/uv 包管理器
COPY --from=ghcr.io/astral-sh/uv:latest /uv /uvx /bin/

# 安装所有 extras
RUN uv pip install hermes-agent[all]

# 非 root 用户（安全）
RUN useradd -u 10000 -m hermes
USER hermes

# 持久化数据
ENV HERMES_HOME=/opt/data
VOLUME /opt/data
```

```bash

hermes gateway start

# 2. 添加任务（对话中）
```

## 安全注意事项

**默认安全行为：**
- gateway 默认不开启（需要手动配置）
- `allowed_users` 默认为空（生产环境请配置白名单）

**生产部署建议：**

```yaml
# config.yaml
channels:
  telegram:
    allowed_users: [123456789, 987654321]  # 只允许指定用户

agent:
  restrict_tools:
    terminal:
      enabled: false                        # 禁用终端执行（高危）
    delegate_task:
      max_concurrent: 1                     # 限制子 Agent 并发
```

**API Key 安全：**
```bash
# 推荐：通过环境变量注入（不写入 config.yaml）
export OPENROUTER_API_KEY=sk-or-v1-xxx
export ANTHROPIC_API_KEY=sk-ant-xxx
hermes
```

## 托管模式（Managed Mode）

适用于系统包管理器安装的场景（NixOS/Homebrew）：

```bash
# 标记为托管模式（防止 Agent 修改包管理的文件）
touch ~/.hermes/.managed
# 或
HERMES_MANAGED=true hermes
```

托管模式下：
- Agent 无法修改 `~/.hermes` 下被标记为托管的文件
- `skill_manage(delete)` 操作受限
- `memory_tool.write()` 限制写入路径
